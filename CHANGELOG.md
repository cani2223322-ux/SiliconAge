## Не выпущено / Unreleased

### Русский
- Вкладка творческого режима «Silicon Age» показывает предметы в постоянном порядке, а не по внутренним номерам: руды → материалы → детали → инструменты и улучшения → машины → энергия → логистика → генератор поля → броня, клинок и бур каждого уровня → оружие. Порядок больше не перемешивается в старых мирах.

### English
- The "Silicon Age" creative tab lists items in a fixed order instead of by internal IDs: ores → materials → parts → tools and upgrades → machines → energy → logistics → field generator → each tier's suit, blade and drill → weapons. It no longer comes out jumbled in old worlds.
