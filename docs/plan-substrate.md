Ф2: **ПП** — поселения и Ядро, **ПЖ** — жители, **ПГ** — стражи, **ПО** — обмен, **ПД** — «Доверие», **ПР** — причалы и возврат (§12–§18). ## 2. Конфиг и совместимость (ПК)

| Код | Правило |
|---|---|
| ПК-1 | Id измерения −1414, id провайдера −1414 (провайдер = id, как у GC, ExU, TC). Положительные id не берём: их раздаёт `getNextFreeDimId` станциям GC и ячейкам AE2. 0, 1 и −1 запрещены |
| ПК-2 | Регистрация в init, на обеих сторонах: провайдер (`registerProviderType` вернул false — выкл.), биомы (поиск свободного слота), измерение (`isDimensionRegistered` до `registerDimension` — иначе краш). Любой отказ — одна понятная строка в логе и выключенная Подложка. Без краша, чужие миры не трогаем. Блоки и предметы зарегистрированы всегда |
| ПК-3 | Id биомов задаются явно: «Кремниевые плато» 240, «Скрайб-каньоны» 241 (резерв 242–244 на Ф4). Если id занят, берётся следующий свободный (240…254, потом вниз до 40; 255 не берётся — в чанке это метка «биом не вычислен»), и выбранный id записывается в конфиг с предупреждением. Мутаций нет. В BiomeManager биомы не добавляются |
| ПК-4 | **Id — в классе-холдере `SubstrateConfigSC`, а не в `public static` полях ConfigSC.** ConfigSyncSC после входа перезаписывает такие поля значениями сервера, а клиент к этому моменту уже зарегистрировал мир со своими. Id приватные, только с геттерами, — синхронизировать нечего. Сервер при входе присылает свои id (`SubstrateNetSC`), клиент сравнивает. При расхождении — строка в логе и в чате; неизвестный клиенту id измерения сервера регистрируется на сессию с провайдером клиента, чтобы вход не крашил. **Правила** (публичные поля холдера) приходят клиенту так же, как ConfigSC, и возвращаются при выходе |
| ПК-5 | `keepLoaded = false`: мир выгружается примерно через 20 с после ухода последнего игрока. Загрузчики чанков держат свои чанки — это нормально |
| ПК-6 | Типы BiomeDictionary задаются явно: WASTELAND, DRY, SPARSE. Никаких FOREST, PLAINS, JUNGLE, SWAMP, WATER, MAGICAL, SPOOKY — иначе ульи, каучук и узлы других модов полезут в мир. Списки спавна биомов пустые, `getPossibleCreatures` пустой: чужие `addSpawn` сюда не дотянутся |
| ПК-7 | Thaumcraft: IMC `dimensionBlacklist` = «<id>:0». AE2: `disableWorldGenForDimension` для Certus и метеоритов через рефлексию; если AE2 нет или он изменился — строка в логе. Своя порода не `minecraft:stone`, поэтому чужие руды (GC, Thermal, DE, IC2, AE2, TC) не появятся |
| ПК-8 | Galacticraft и GalaxySpace: провайдер наследует WorldProvider, а не WorldProviderSurface. Не реализует IGalacticraftWorldProvider и IZeroGDimension, небесного тела не регистрируем. В `FMLLoadCompleteEvent` — проверка `GalaxyRegistry.getCelestialBodyFromDimensionID(id)` через рефлексию и повторная проверка слотов биомов и типа провайдера: при совпадении — громкое предупреждение. Зависимость `after:GalacticraftCore`. Ракеты: взлёт отсюда разрешён, в README — как запретить вручную |
| ПК-9 | Сущности — только `EntityRegistry.registerModEntity` под SiliconAge, свой пул с 0 (у Vehicles свой). Глобальный пул 0–255 не трогаем, яйцо призыва своё. Зелья и чары не нужны |
| ПК-10 | Мультиплеер: всё серверное решает сервер, клиент только показывает. На клиенте мир определяется по классу провайдера (`SubstrateSC.is(world)`), не по сравнению id |

## 4. Вход и мост (ПВ)

| Код | Правило |
|---|---|
| ПВ-1 | Измерение само появляется в списке Космического моста (`buildDimList` берёт `getStaticDimensionIDs`) и видно всем. Наземный мост в чужие измерения не ходит (`refuse.groundDim`). Нужен `bridge.crossDimension = true` |
| ПВ-2 | Законный вход — только тот, который ядро разрешило заранее: `BridgeTeleportSC.teleport` выдаёт игроку «пропуск» на ближайшие тики перед переносом в Подложку. Через этот же метод аддон Vehicles переносит седоков при «Прыжке», поэтому Прыжок уже разрешён. Для следующего релиза аддона есть хук `SubstrateEntrySC.allowsArrival(player, via)`; аддон не трогаем |
| ПВ-3 | `strictEntry = true`: игрок, попавший в Подложку без пропуска (Advanced Dislocator DE, межизмеренческие телепорты других модов), на следующем тике отправляется назад. Назад — в измерение, откуда пришёл, в последнюю безопасную точку там; если её нет — на спавн того мира. Перенос идёт через очередь (`TeleportQueueSC`), не изнутри чужого переноса, с проверкой места. Креатив и операторы пропускаются. Отменить переход заранее нельзя: в Forge 1614 нет `EntityTravelToDimensionEvent` |
| ПВ-4 | Адский портал не работает: ядро раз в 10 тиков держит `timeUntilPortal ≥ 20` у всех сущностей в Подложке. Рамка искрит, в чат — «Прокол глушит портал» (не чаще раза в 3 с). Иначе портал был бы бесплатным выходом через Nether в dim 0 |
| ПВ-5 | Имя в мосте: `getDimensionName` = «Si-14 Substrate» для логов. Провайдер реализует `INamedDimensionSC`, и `buildDimList` кладёт рядом lang-ключ. Окна моста показывают «Подложка (Si-14)» / «Substrate (Si-14)» |
| ПВ-6 | Цена: при переходе между измерениями, если один из концов в Подложке, цена × `dimension.bridgeCostMultiplier` (0,5) поверх `bridge.costMultiplier`, в `plan()`. Внутри Подложки множитель не действует. Якорь в генерации не ставим: первый игрок со своим якорем снимает ×2 для всех (общая метка, как сейчас) |
| ПВ-7 | Первая высадка: правило С7 моста (разведка без якоря сносит конец до 100 блоков) и мягкое приземление `BridgeSoftLandSC` — уже работают. При каждом законном прибытии — «Буфер прокола»: 10 с Сопротивления II. При первом — сообщение «Канал стабилен. Вы по ту сторону прокола. Местные называют этот мир Подложкой.» и подсказка открыть главу справочника. Ядро запоминает точку отправления: она нужна Капсуле возврата в Ф2 |
| ПВ-8 | `nativesCrossBridge = false`: сущности с маркером `ISubstrateNativeSC` не проходят через мост в другое измерение даже с Компенсатором массы — ни в `enter()`, ни через `BridgeTeleportSC`. Флаг «рождён в Si-14» снимается при входе сущности в любой другой мир |
| ПВ-9 | Смерть: возрождение в `respawnDimension`. Метка гибели и Утилизатор — Ф2 / Ф4 |
| ПВ-10 | Кровать: ПКМ по кровати в Подложке отменяется с сообщением «Здесь не уснуть: прокол гудит всю ночь». Ловить именно ПКМ: при `canRespawnHere = false` ванильная кровать взрывается в `onBlockActivated` раньше, чем сработает `PlayerSleepInBedEvent`. Это событие тоже ловим — для кроватей других модов |

## 5. Броня мобов и ПЭ-1 (ПБ)

| Код | Правило |
|---|---|
| ПБ-1 | Броня на мобе — только для вида: надетые стеки не меняются. Запас, щит и подавление хранятся в полях сущности и в DataWatcher (`IArmoredMobSC` → `MobArmorSC`). Код брони игрока (`ItemArmorSC`, `ArmorLogicSC`) мобов не касается |
| ПБ-2 | **Запас** — в единицах урона. Пока он больше 0, блокируемый удар теряет min(1, очки / 25), и эта часть списывается из запаса. Очки — по частям мода: Нано 20 = 80%, Квант 22 = 88%, Экзо 24 = 96%, Сингулярная 28 = 100% |
| ПБ-3 | Удар в обход брони и абсолютный урон (Экзо-клинок, пробой Кванта) проходит мимо брони прямо в HP. Остановить его может только щит |
| ПБ-4 | **Щит** — только у Экзо- и Сингулярных мобов с гелием и неподавленным нагрудником. Он первым принимает любой урон, включая обход брони и абсолютный (кроме outOfWorld и радиации), и списывает его из запаса; остаток, на который запаса не хватило, идёт дальше. Броня и щит работают в `damageEntity`, после того как ванильные кадры неуязвимости уже срезали удар, — серия ударов не спишет запас дважды |
| ПБ-5 | **Аварийный режим** — как у игрока: только Квант, Экзо и Сингулярная без гелия дают очки железной брони и не дают щита. У Нано аварийного режима нет — поправка к §8 предложения: Обходчик в Ф1 — обычная Нано-броня, его слабость — 1–3 части и маленький запас |
| ПБ-6 | Запас кончился — броня «села»: защиты нет, свечение гаснет, искры, звук `power.off` |
| ПБ-7 | Подзарядка — в единицах запаса. Ф1: Обходчик и Мародёр с пустым запасом идут к Медной трассе и набирают 1 ед./с, пока стоят рядом. Часовой, дроны, плита — позже |
| ПБ-8 | «Казнь» клинка не действует на мобов с маркером `IExecuteImmuneSC` (элита, Часовой, Затмение, Вожак — с Ф3). `IBossDisplayData` есть только у босса |
| ПБ-9 | Урон оружия мобов ограничен (ПС-4). Пробой брони, абсолютный урон и «Казнь» из `BladeLogicSC` работают только у игрока |
| ПБ-10 | ПЭ-1 по мобу — через `IEmpTargetSC`, за флагом `dimension.empMobTargets` (вкл.). Правила те же, что против игрока: длительности из EmpMathSC по костюму части (Нано Точка 16 с / Импульс 14 с … Сингулярная 8 / 6), 20 с невосприимчивости после подавления, гелий −20%. Подавленная часть даёт очки железной брони. Точка в нагрудник Экзо- или Сингулярного моба снимает и щит. Импульс не бьёт INpc (кроме стражей купола, ПГ-20) и питомцев. Мобы без `IEmpTargetSC` — по-старому, Медлительность 2 с |
| ПБ-11 | Сифон по мобу — за флагом `dimension.siphonMobs` (вкл.): доля **полного** запаса в секунду по костюму нагрудника (6 / 5 / 4 / 3%). Энергия — единицы × EU костюма за единицу (Нано 500 … Сингулярная 8000), потери как у игрока. Пока идёт поток, подзарядка моба стоит |
| ПБ-12 | За один поток Сифон даёт ПЭ-1 не больше 50 000 EU; моб после этого продолжает терять запас, лишнее уходит в искры |
| ПБ-13 | Регресс PvP исключён: путь «цель — игрок» в `EmpGunLogicSC` и `EmpSiphonSC` не меняется, ветка мобов идёт отдельно и только при включённых флагах. Существующий мировой тест ПЭ-1 на игроках проходит без изменений |
| ПБ-14 | Свечение брони моба (ModelArmorGlowSC) берёт заряд, «села», подавление и Сифон из DataWatcher; цвет — из `glowColor` стеков, его ставят при спавне (Обходчик — жёлтый, Мародёр — оранжевый); дальше 32 блоков свечение не рисуется |

| Уровень | Очки | Запас на спавне | Выстрелов Плазменной винтовки (12) | Щит | Точка / Импульс | Сифон, % полного запаса в секунду |

## 10. Проверка Ф1 в реальной сборке

Вход Космическим мостом. Лог без «clash» и без предупреждений Подложки. Мир выгружается примерно через 20 с после ухода. F3: биомы, свет. JourneyMap в режиме поверхности. Ночное зрение шлема. Небо GC и GS не подменено, GS не душит игрока. Нет узлов TC. Адский портал заглушён. Кровать не взрывается. Dislocator DE возвращает игрока назад. Игра по LAN с другом: id совпали; при намеренной разнице — предупреждение в чате. Обходчики и Мародёры: броня садится, ПЭ-1 их подавляет и выкачивает, трофеи и добыча падают только с настоящего игрока.

## 11. Не входит в Ф1

Поселения, торговля, репутация, стражи. Структуры, кроме рельефа. Мобы, кроме Обходчика и Мародёра. ПЭ-1 в руках мобов. Урон «Пробой». WAILA и Анализатор. Радиация, ЭМИ-буря, своя погода. Фумаролы, трещины, жеоды. Капсула возврата, Метка гибели. Восстановление трофеев. `customSky`, `requireSignal`.

## 52. Проверка Ф5 в реальной сборке
Вместе с Ф1–Ф4 (§10 и техпланы): арена и бой вдвоём по LAN (HP 960, добыча обоим, сброс через 5 мин, выгрузка мира посреди боя), журналы, обломки, луч Сигнала на горизонте, караван с засадой, схемы и Запись у каждого свои, своё небо и ShadersModCore. ## 53. Не входит в Ф5
Светодиодные мотыльки, Собиратели и «спасти Собирателя», Дрон-наладчик, свои «модемные» звуки (по желанию пакетов), ракеты GC в Подложку (ПВ-11), новые биомы. Мир «зелёный с одной луной» — крючок на будущее, не часть Ф5.
