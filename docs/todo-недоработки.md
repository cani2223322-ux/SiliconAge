# Silicon Age — недоработки (ждут решения)

Формат: номер → суть → варианты (М — малая, С — средняя, Б — большая сложность). ★ — рекомендация.

## Сделано
- 2026-10-01, коммит 10ccca6: Г1–Г10, М1–М8, Э1–Э7, К1–К12.
- 2026-10-01, коммиты a280525 и 1c3772c:
  - Б2–Б7, Б9–Б13, Б15, Б16 (своим вариантом: поле не разворачивается поверх чужого);
  - Ч1 (только киркой) — Ч13;
  - П1 (статус «выходной бак занят»), П3–П6.
- Оставлены по решению пользователя: Б1 (нерф брони позже), Б8, Б14, П2.

## Ждёт разрешения
- **Регистрация предмета-блока генератора поля** в `init/ModBlocks.java`. Без неё не работают подсказка и перенос заряда и настроек поля в предмете.
  - Замена: `registerBlock(fieldGeneratorSC, "fieldGeneratorSC")` → `registerBlock(fieldGeneratorSC, com.sc.block.ItemBlockFieldGeneratorSC.class, "fieldGeneratorSC")`.
  - Имя регистрации не меняется.

## Решение по сделанному
- **Э2-доп. Потери «генератор → накопитель» теперь считаются по длине линии.**
  1) ★ Оставить. 2) Вернуть без потерь (М).
- **М8-доп. Машины с зарядом в предмете не стакаются.**
  1) ★ Оставить. 2) Сохранять заряд только больше 1% буфера (М).
- **Б16-доп. Проверка чужого поля.**
  - Связывание узлов модулем связи расширяет зону без проверки.
  - Вставка настроек ключом и смена формы Shift+ПКМ при отказе ничего не пишут.
  1) ★ Проверка при связывании плюс сообщение в чат при любом отказе (М). 2) Оставить.
- **П6-доп. Модуль «Удержание чанков» отпускает чанки при полном буфере или без энергии.** Автостоп без игрока рядом не продолжится сам.
  1) Держать чанки и при BUFFER_FULL / NO_POWER (М). 2) ★ Держать при BUFFER_FULL, отпускать без энергии (М). 3) Оставить.
- **П3-доп. В старых мирах два горящих токамака на общем порту.** После загрузки один из них получит «порт занят» и остановится.
  1) ★ Оставить: ситуация редкая, в списке изменений есть пояснение. 2) Не отбирать порт у горящего никогда (М).

- **Б8. Предпросмотр зоны поля** остаётся после закрытия экрана — оставлено.
- **Б13. Огнеупорность бесплатно между проверками** (М) — не выбрано.
- **Б14. Бур площадью не учитывает твёрдость** — оставлено.
- **П2. Машина с модулями как ингредиент теряет модули** — оставлено.
- **П7. Заглушка IMultiEnergySource не сверена с IU.**
  1) ★ Сверить по jar (М). 2) Сверить плюс тест (М). 3) Компилировать против IU (С). 4) Оставить.

## Проверка 2026-10-02 (новые изменения, коммит 2981d25)
- **Н1. Автостоп карьера отпускает чанки** - без игрока рядом карьер сам не продолжит. 1) держать при автостопе; 2) ★ держать 5 мин после автостопа; 3) описать в справочнике.
- **Н2. Запрет поля поверх чужого видит только активные поля** - можно занять место у обесточенного соседа. 1) все загруженные поля; 2) ★ старшинство по времени установки (С); 3) оставить.
- **Н3. Старые уже перекрытые поля:** любая смена зоны откатывается. 1) ★ разрешать, если старая зона уже пересекала то же поле; 2) разрешать не увеличивающие пересечение (С); 3) оставить.
- **Н4. Проверка перекрытия полей дорогая на каждый пакет зоны.** 1) ★ ограничить частоту пакетов; 2) грубее сетка; 3) кэш.
- **Н5. Нет настройки конфига для удержания чанков карьером.** 1) ★ quarryChunkLoading в конфиге; 2) лимит на игрока (С).
- **Н6. Приват поля не защищает от стрел и снежков** по животным. 1) ★ LivingAttackEvent от чужого игрока; 2) плюс рамки и картины (С).
- **Н7. Игрок из списка доступа может сломать и переставить поле, став владельцем.** 1) ломать мастер только владельцу/OP; 2) ★ владелец в предмете, возвращается, если ставящий в списке доступа (С).
- **Н8. Излучение при «Сбросе» реактора к концу растёт** (лёгкая дыра). 1) ★ уровень по начальной массе, убывает со временем; 2) фиксированный; 3) оставить.
- **Н9. Аргон не возвращает заряд, «Сброс» - 20%.** 1) ★ оставить; 2) 10%.
- **Н10. Дейтерий при сжатии не расходуется (а комментарий пишет, что да).** 1) ★ поправить комментарий; 2) тратить 0,25 мБ/т и при сжатии.
- **Н11. Двойной щелчок слива машины быстрее 0,4 с не срабатывает.** 1) порог 4 тика; 2) ★ текст «нажмите ещё раз через секунду».
- **Н12. Компрессор: фильтр редкости опирается на getRarity**, у некоторых модов он только клиентский. 1) ★ убрать редкость, явный чёрный список + список в конфиге; 2) оставить.
- **Н13. Генераторные блоки 23/32** - нет защиты от переполнения, как у машин. 1) ★ добавить проверку при запуске.
- **Н14. Квантовый транслятор при полном приёмнике держит оба чанка бесплатно и бессрочно.** 1) ★ держать без платы не дольше 10 с, потом отпускать; 2) платить, но не изнашивать кристалл; 3) описать.
- **Н15. Под IC2 адаптивный трансформатор за кабелем мода не повышает** (сеть мода не строится). 1) ★ сейчас - честный текст «под IC2 только вплотную»; 2) позже - обход кабелей мода (С).
- **Н16. Переанонс IC2 при каждой смене адаптивного уровня.** 1) убрать (риск для IU); 2) ★ не чаще раза в секунду.
- **Н17. Предупреждения в лог IC2 «not added to the enet»** раз в 2 тика у отложенных кабелей. 1) ★ проверять регистрацию перед запросом; 2) оставить.
- **Н18. Назначение доп. выхода ключом не предупреждает о слабом кабеле на грани.** 1) ★ вызвать предупреждение о кабеле.
- **Н19. Снятый накопитель теряет назначенные доп. выходы.** 1) хранить в предмете (С); 2) ★ оставить.
