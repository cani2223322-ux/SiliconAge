# Silicon Age — недоработки (ждут решения)

Формат: номер → суть → варианты (М — малая, С — средняя, Б — большая сложность). ★ — рекомендация.

## Сделано
- 2026-10-01, коммит 10ccca6: Г1–Г10, М1–М8, Э1–Э7, К1–К12.
- 2026-10-01, коммиты a280525 и 1c3772c:
  - Б2–Б7, Б9–Б13, Б15, Б16 (своим вариантом: поле не разворачивается поверх чужого);
  - Ч1 (только киркой) — Ч13;
  - П1 (статус «выходной бак занят»), П3–П6.
- Оставлены по решению пользователя: Б1 (нерф брони позже), Б8, Б14, П2.

## Ждёт разрешения
- **Регистрация предмета-блока генератора поля** в `init/ModBlocks.java`. Без неё не работают подсказка и перенос заряда и настроек поля в предмете.
  - Замена: `registerBlock(fieldGeneratorSC, "fieldGeneratorSC")` → `registerBlock(fieldGeneratorSC, com.sc.block.ItemBlockFieldGeneratorSC.class, "fieldGeneratorSC")`.
  - Имя регистрации не меняется.

## Решение по сделанному
- **Э2-доп. Потери «генератор → накопитель» теперь считаются по длине линии.**
  1) ★ Оставить. 2) Вернуть без потерь (М).
- **М8-доп. Машины с зарядом в предмете не стакаются.**
  1) ★ Оставить. 2) Сохранять заряд только больше 1% буфера (М).
- **Б16-доп. Проверка чужого поля.**
  - Связывание узлов модулем связи расширяет зону без проверки.
  - Вставка настроек ключом и смена формы Shift+ПКМ при отказе ничего не пишут.
  1) ★ Проверка при связывании плюс сообщение в чат при любом отказе (М). 2) Оставить.
- **П6-доп. Модуль «Удержание чанков» отпускает чанки при полном буфере или без энергии.** Автостоп без игрока рядом не продолжится сам.
  1) Держать чанки и при BUFFER_FULL / NO_POWER (М). 2) ★ Держать при BUFFER_FULL, отпускать без энергии (М). 3) Оставить.
- **П3-доп. В старых мирах два горящих токамака на общем порту.** После загрузки один из них получит «порт занят» и остановится.
  1) ★ Оставить: ситуация редкая, в списке изменений есть пояснение. 2) Не отбирать порт у горящего никогда (М).

## Остались с прошлых списков
- **Б1. Энергощит Экзо гасит голод, утопление и удушье** — отложено до нерфа брони.
- **Б8. Предпросмотр зоны поля** остаётся после закрытия экрана — оставлено.
- **Б13. Огнеупорность бесплатно между проверками** (М) — не выбрано.
- **Б14. Бур площадью не учитывает твёрдость** — оставлено.
- **П2. Машина с модулями как ингредиент теряет модули** — оставлено.
- **П7. Заглушка IMultiEnergySource не сверена с IU.**
  1) ★ Сверить по jar (М). 2) Сверить плюс тест (М). 3) Компилировать против IU (С). 4) Оставить.
